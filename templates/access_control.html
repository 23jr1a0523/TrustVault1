Roles & Permissions

How different roles access TrustVault resources.

ACCESS POLICY
👤
USER ROLE

Document Owner

Users can view and download only documents associated with their account. The server checks ownership before allowing a download.

PERMISSIONS & PROTECTION
✓ View documents associated with their account
✓ Download their own documents
✓ Ownership is checked by the server
🛡️
ADMIN ROLE

Administrator

Administrators can access the audit logs page. Ordinary users are denied access to that page.

ADMINISTRATIVE ACCESS
✓ Access the audit logs page
✓ Review recorded activity in audit logs
✓ Administrator access is checked by the server
🔐

Server-Side Authorization

Access checks happen on the server, not just by hiding links in the website. This helps prevent users from accessing restricted pages or downloading documents they do not own.
